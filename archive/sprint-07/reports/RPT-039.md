## Ringkasan (Summary)
Telah menyelesaikan ekstraksi tuntas seluruh modul channel sisa monolit di `crates/clawcrew-channels` menjadi tiga crate independen di `crates/galleon-channel-*`: `galleon-channel-git`, `galleon-channel-voice-call`, dan `galleon-channel-whatsapp`. Monolit `clawcrew-channels` sekarang mere-ekspor fungsionalitas channel melalui feature flags dan decoupling dynamic trait (`AudioTranscriber` dan `TextToSpeechSynthesizer`), mengisolasi dependensi berat SDK pihak ketiga (seperti WhatsApp Web Rust stack, Twilio/Telnyx axum client, jsonwebtoken) keluar dari monolit inti. Seluruh 895 test pada `clawcrew-channels` dan 341 test pada ketiga crate baru lulus 100%, serta PR #78 telah dibuka ke branch `testing`.

## Yang Dikerjakan (What Was Done)
1. **Ekstraksi Crate Baru**:
   - `crates/galleon-channel-git`: Memisahkan adapter Git (GitHub & Gitea), webhook server, polling router, events dispatching, dan comment splitting. Menggunakan `jsonwebtoken` aman (`aws_lc_rs`, `use_pem`) dan `galleon-channel-core` allowlist.
   - `crates/galleon-channel-voice-call`: Memisahkan endpoint dan webhook voice-call untuk Twilio, Telnyx, dan Plivo.
   - `crates/galleon-channel-whatsapp`: Memisahkan seluruh stack WhatsApp Cloud API, WhatsApp Web QR pairing (`whatsapp-rust`, `wacore`, `waproto`), dan SQLite session storage.
2. **Decoupling Dynamic Trait & Re-export**:
   - Mendefinisikan trait `AudioTranscriber` dan `TextToSpeechSynthesizer` di `galleon-channel-whatsapp`.
   - Mengimplementasikan trait-trait tersebut pada `TranscriptionManager` dan `TtsManager` di `clawcrew-channels`.
   - Mempertahankan backward compatibility API monolit melalui module re-exports (`git`, `voice_call`, `whatsapp`, `whatsapp_storage`, `whatsapp_web`).
3. **Penyelarasan Workspace & Architecture Gate**:
   - Mendaftarkan ketiga crate baru pada root `Cargo.toml` (`[workspace.members]` dan `[workspace.dependencies]`).
   - Mendaftarkan crate baru pada `tests/architecture/dependency_direction.rs`.
   - Memperbarui pelacakan batas ukuran berkas pada `tests/architecture/module_size_limits.rs`.
   - Melengkapi metadata manifest `crates/galleon-channel-wecom-ws/Cargo.toml` (`publish = true`, `repository.workspace = true`) sehingga test architecture `release_set` lulus.
