### 1. Bukti & Hasil Implementasi

1. **Autentikasi Ingress Channel Berbasis Cryptographic HMAC SHA-256 Nyata:**
   - Menjalankan channel webhook nyata ([`WebhookChannel`](file:///home/diezy/Apps/galleon-fleet/crates/clawcrew-channels/src/webhook.rs)) pada ephemeral loopback port (`127.0.0.1:0`).
   - Mengirim request HTTP POST nyata bertanda tangan cryptographic HMAC SHA-256 (`X-Hub-Signature-256: sha256=<hex>`) menggunakan [`hmac::Hmac<sha2::Sha256>`](file:///home/diezy/Apps/galleon-fleet/tests/channel_egress_e2e.rs#L85-L105).
   - Memverifikasi HTTP 200 OK dan penerimaan payload utuh pada receiver channel.
2. **Penolakan Request Tidak Sah & Validasi Boundary Signature:**
   - Request dengan signature cacat/korup (`sha256=badhex...`) ditolak tegas dengan status HTTP 401 Unauthorized dan nol payload diteruskan ke channel.
   - Request tanpa header signature pada secured channel ditolak langsung dengan status HTTP 401 Unauthorized.
   - Request dengan payload yang dimanipulasi/tampered ditolak dengan HTTP 401 Unauthorized.
   - Verifikasi timestamp freshness window (300 detik) menggunakan implementasi HMAC kriptografis asli; request dengan timestamp kadaluarsa ditolak tegas.
3. **Enforcement Sandbox Egress Jaringan Keluar (Real TCP Socket Listener):**
   - Menjalankan TCP listener nyata pada loopback lokal (`127.0.0.1:0`) dengan counter koneksi atomik.
   - Mengonfigurasi sandbox egress policy via [`NetworkGuard`](file:///home/diezy/Apps/galleon-fleet/crates/clawcrew-infra/src/net_guard.rs).
   - Memverifikasi koneksi outbound diizinkan hanya ketika destination grant diberikan (`allow_private: true` dan host loopback terdaftar), dan koneksi berhasil mencapai socket listener lokal (`hits == 1`).
4. **Pemblokiran Mutlak Koneksi Tanpa Izin:**
   - Egress ke host/tujuan tanpa grant diblokir tegas di boundary sandbox sebelum network socket dial (`NetworkGuardError::PrivateHostDenied`), menghasilkan `hits == 0`.
   - Egress ke alamat private/loopback tanpa carveout eksplisit (`allow_private: false`) diblokir mutlak oleh sandbox host (`hits == 0`).
   - Destination port tidak valid (port 0) ditolak langsung (`NetworkGuardError::InvalidPort`).
5. **E2E Test Suite di [`tests/channel_egress_e2e.rs`](file:///home/diezy/Apps/galleon-fleet/tests/channel_egress_e2e.rs):**
   - Mengonsolidasikan 10 test E2E menyeluruh tanpa mock stubs, sekaligus memelihara WASM Cranelift test fixture di bawah feature flag module `#[cfg(feature = "plugins-wasm-cranelift")]`.
