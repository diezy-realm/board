## Ringkasan (Summary)
Rangkaian pengujian integrasi End-to-End (E2E) untuk alur mutasi konfigurasi, persistensi fisik secara atomik, dan deteksi pergeseran (drift detection) pada filesystem nyata tanpa mock store telah selesai diimplementasikan di `crates/clawcrew-gateway/tests/api_config_persistence_drift_e2e.rs`. Seluruh 3 test case E2E baru serta 58 unit test yang ada (total 61/61 test) lulus 100% pada `cargo nextest run -p clawcrew-gateway -E 'test(api_config)' --locked`. Commit telah di-push dan Pull Request dibuka ke branch `testing` (PR #79).

## Yang Dikerjakan (What Was Done)
1. **Physical Filesystem Setup & Test Configuration:**
   - Menyiapkan direktori fisik sementara via `tempfile::tempdir()` dan menulis berkas fisik `config.toml` valid ke disk menggunakan real filesystem I/O (`std::fs::write`).
2. **RFC 6902 JSON Patch Mutation via `/api/config`:**
   - Menjalankan Axum gateway listener pada socket TCP ephemeral lokal (`127.0.0.1:0`).
   - Mengirim mutasi konfigurasi melalui operasi JSON Patch RFC 6902 (`op: replace`, paths: `/gateway/port` dan `/gateway/host`) via HTTP client nyata `reqwest` ke endpoint `/api/config`.
   - Memvalidasi HTTP status 200 OK, `saved: true`, dan `results` merekam nilai hasil patch.
3. **Atomic Disk Persistence & Consistent State Swap Verification:**
   - Membaca ulang berkas fisik `config.toml` langsung dari disk (`std::fs::read_to_string`) dan mem-parse ulang ke struct `Config`.
   - Memverifikasi nilai on-disk persis sesuai patch (`gateway.port = 9099`, `gateway.host = "127.0.0.2"`).
   - Memverifikasi konsistensi in-memory state swap (`state.config.read()`) dan penandaan `state.pending_reload`.
   - Menguji pemanggilan langsung `persist_and_swap` dengan guard lock kepemilikan.
4. **Live External Disk Modification & Drift Detection:**
   - Memodifikasi berkas fisik `config.toml` di disk secara langsung/eksternal tanpa melalui runtime (`std::fs::write`).
   - Memanggil fungsi `try_compute_drift(&state.config.read())` dan memverifikasi diff `ConfigDriftSummary` mendeteksi pergeseran dengan tepat (`gateway.port`: in_memory `8080` vs on_disk `7777`, `drifted: true`, `secret: false`).
   - Mendaftarkan rute `GET /api/config/drift` di `crates/clawcrew-gateway/src/gateway.rs` dan memverifikasi HTTP response mengembalikan data drift identik.
   - Menguji penolakan mutasi conflicting path tanpa header override (HTTP 409 Conflict dengan code `config_changed_externally`).
   - Menguji keberhasilan override dengan header `X-ClawCrew-Override-Drift: true`, persistensi ulang ke disk, dan verifikasi pergeseran kembali bersih (`try_compute_drift` mengembalikan drift kosong).
5. **Pengeksposan Facade & Public Re-exports:**
   - Menambahkan type alias `pub type ConfigDriftSummary = Vec<DriftEntry>;` di `crates/clawcrew-gateway/src/api_config/drift.rs`.
   - Mengubah visibilitas `try_compute_drift` dan `persist_and_swap` menjadi `pub` dan mengekspornya di `crates/clawcrew-gateway/src/lib.rs`.
