## Ringkasan (Summary)
Telah menyelesaikan migrasi penuh variabel lingkungan dari prefix `CLAWCREW_*` ke `GALLEON_*` di seluruh codebase tanpa fallback dual-read aliases (SPEC-009 / dev-task-3 T3-18 / RB-22 / RB-23). Direktori konfigurasi baku dipindahkan ke `~/.config/galleon` (`%APPDATA%\galleon` di Windows), socket IPC diganti ke `GALLEON_SOCKET` (`galleon.sock`), dan modul first-boot atomic data migration beserta shell script migrasi telah diimplementasikan dengan test suite yang lolos 100%. PR telah dibuka ke branch `testing`.

## Yang Dikerjakan (What Was Done)
1. **Migrasi Variabel Lingkungan Tanpa Dual-Read:**
   - Mengubah konstanta prefix `PREFIX: &str = "GALLEON_"` di `crates/galleon-config/src/env_overrides.rs`.
   - Mengganti seluruh referensi env `CLAWCREW_*` menjadi `GALLEON_*` di seluruh crates (`galleon-config`, `galleon-runtime`, `galleon-channels`, `galleon-gateway`, `galleon-infra`, `galleon-plugins`, `galleon-memory`, `galleon-tls`, `galleon-tools`), apps (`galleoncode`, `galleonrelay`), tests, scripts, demo, dan Dockerfiles.
2. **First-Boot Atomic Data Migration:**
   - Membangun `crates/galleon-config/src/config_migration.rs` dengan fungsi `migrate_config_directory()` yang menyalin berkas/direktori dari `~/.clawcrew` ke `~/.config/galleon` via atomic temp dir swap dan membuat penanda `.migrated` di kedua direktori.
   - Mengintegrasikan migrasi otomatis saat boot pertama di `Config::load_or_init()` (`crates/galleon-config/src/schema.rs`).
   - Menyediakan standalone executable migration shell script `scripts/migrate-clawcrew-to-galleon.sh`.
   - Memperbarui python migration script `scripts/migrations/migrate_state.py` untuk menulis penanda `.migrated`.
3. **Pusat Direktori Konfigurasi Tanpa Dual-Read:**
   - Mengubah default config dir di `crates/galleon-config/src/schema.rs` menjadi `~/.config/galleon` (Linux/macOS) dan `%APPDATA%\galleon` (Windows).
   - Memperbarui runtime adapter storage paths di `crates/galleon-config/src/platform/native.rs` dan `docker.rs`.
   - Menghapus dual-read fallback ke `.clawcrew` pada resolusi data/workspace.
4. **Migrasi IPC Socket & Konstanta Operasional:**
   - Mengubah prefix IPC socket dari `CLAWCREW_SOCKET` ke `GALLEON_SOCKET` dan berkas socket default ke `galleon.sock` (Windows named pipe `\\.\pipe\galleon-{:x}`).
   - Memperbarui service names, launchd plist labels (`com.galleon.daemon`), systemd (`galleon.service`), openrc (`/etc/init.d/galleon`, `rc-service galleon restart/status`), task name (`Galleon Daemon`), log paths (`/var/log/galleon/access.log`), sync markers (`.galleon-open-skills-sync`), memory snapshot headers (`# 🧠 Galleon Memory Snapshot`), dan deprecation header (`x-galleon-deprecation`).
5. **Pengujian & Verifikasi:**
   - Menambahkan integration test suite `crates/galleon-config/tests/config_migration.rs` (6 test cases).
   - Menjalankan `cargo test -p galleon-config --test config_migration` (6 passed, 0 failed).
   - Menjalankan smoke migration test `python3 tests/migration/test_upgrade_smoke.py` (passed).
   - Menguji shell script `scripts/migrate-clawcrew-to-galleon.sh` pada mock directories (passed).
