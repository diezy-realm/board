1. **Ekstraksi Submodul Channels (`api/channels.rs` - 385 baris):**
   - Handler `handle_api_channels` dan `handle_api_channel_relink`.
   - Logika evaluasi kesiapan channel: `channel_readiness`, `build_channel_summary`, `probe_persisted_login_readiness`, `probe_webhook_readiness`, dan helper string formatter.
2. **Ekstraksi Submodul Memory (`api/memory.rs` - 234 baris):**
   - Handler memory: `handle_api_memory_list`, `handle_api_memory_store`, dan `handle_api_memory_delete`.
   - DTOs terkait memory: `MemoryQuery`, `MemoryStoreBody`, `MemoryDeleteBody`, `MemoryEntryJson`.
   - Resolving & sanitasi: `resolve_memory_handle`, `sanitize_memory_entries_for_api`, dan `truncate_with_ellipsis_total_chars`.
3. **Ekstraksi Submodul Integrations (`api/integrations.rs` - 81 baris):**
   - Handler integrasi: `handle_api_integrations` dan `handle_api_integrations_settings`.
   - DTO serialisasi: `integration_entry_json`.
4. **Perampingan & Penataan `api/mod.rs` (485 baris):**
   - Re-export transparan penuh:
     ```rust
     pub use channels::*;
     pub use cron::*;
     pub use integrations::*;
     pub use memory::*;
     pub use sessions::*;
     ```
   - Seluruh router Axum di `lib.rs` dan seluruh integration test tetap mengacu ke modul `api` tanpa perubahan signature atau path.
   - Preservasi berkas `api/tests.rs` (zero touch) dengan conditional re-export `#[cfg(test)] pub(crate) use axum::extract::Path;` di `api/mod.rs` guna mencegah modifikasi pada file legacy yang belum lolos ratchet rustfmt.
   - Format import alfabetis sesuai standar Rust Edition 2024.
