## Ringkasan (Summary)
Telah diselesaikan implementasi jembatan identitas BL-001 / TASK-016. Bug konkret di mana `services.go:91` mengabaikan `agentID` yang sudah di-resolve dan meng-hardcode `Model: "gpt-4o"` telah diperbaiki dengan menambahkan field opsional `agent_alias = 8` pada message `ExecuteTurnRequest` protobuf (`proto/agent_service.proto`). Kode Go pb di-regenerate via `protoc`, `StartTurn` di Go kini meneruskan `AgentAlias: &agentID` (dan pada `runSubagent` meneruskan `AgentAlias: &subagentID`). Pada sisi Rust (`crates/clawcrew-gateway/src/grpc_system_gateway.rs`), `SystemGatewayService` kini mendukung konfigurasi (`with_config`), dan handler RPC `execute_turn` me-resolve `agent_alias` ke `config.agents.get(alias)`. Bila ditemukan, `AliasedAgentConfig.model_provider` digunakan sebagai effective model; bila tidak ditemukan atau kosong, sistem fallback secara graceful ke model default/requested tanpa crash atau panic.

## Yang Dikerjakan (What Was Done)
1. **Verifikasi Fakta Codebase**: Memeriksa `proto/agent_service.proto` (field 1..7 terpakai, slot kosong berikutnya adalah 8), `engine/src/crew/services.go` baris 75-97 (`agentID` di-resolve tapi dibuang, diganti hardcode `gpt-4o`), dan `crates/clawcrew-gateway/src/grpc_system_gateway.rs` (handler `execute_turn`).
2. **Proto Update**: Menambahkan `optional string agent_alias = 8;` ke `ExecuteTurnRequest` pada `proto/agent_service.proto`.
3. **Protobuf Stubs Generation**: Menjalankan compiler `protoc` resmi (`scripts/generate_proto.ps1` command) untuk meregenerasi stubs Go di `engine/pkg/pb/agent_service.pb.go`.
4. **Go Engine StartTurn**: Mengganti `Model: "gpt-4o"` di `engine/src/crew/services.go` dengan `AgentAlias: &agentID`. Pada subagent worker, menyematkan `AgentAlias: &subagentID`.
5. **Rust SystemGateway**:
   - Menambahkan field `config: Option<std::sync::Arc<clawcrew_config::schema::Config>>` dan method builder `with_config` pada `SystemGatewayService`.
   - Menambahkan logic resolusi di handler `execute_turn`: jika `req.agent_alias` terisi dan ditemukan di `config.agents.get(alias)`, model provider dari konfigurasi agen tersebut digunakan.
   - Jika alias kosong atau tidak ditemukan dalam konfigurasi, sistem fallback ke `req.model` atau `"default"` secara fail-safe dengan structured logging (`clawcrew_log::record!`).
6. **Testing**:
   - Unit tests Go di `engine/src/crew/crew_test.go` (`TestCrewAgentAliasResolution`): memverifikasi `AgentAlias` diteruskan dengan benar pada explicit agentID maupun fallback ke `"primary_agent"`, serta memastikan hardcode `"gpt-4o"` sudah dihapus.
   - Unit tests Rust di `crates/clawcrew-gateway/src/grpc_system_gateway.rs`: skenario alias valid (`test_execute_turn_with_valid_agent_alias`), alias tidak terdaftar (`test_execute_turn_with_unknown_agent_alias_fallback`), dan alias kosong (`test_execute_turn_with_empty_agent_alias_fallback`), serta backward-compatibility pada `test_execute_turn_success`.
