## Story
Sebagai **Tech Lead & Tim Engineering Galleon**, saya ingin **memvalidasi seluruh subsistem kritis Galleon Fleet (Gateway REST/WS, Konfigurasi & Drift, Channel Ingress/Egress, dan Persistence Memory) melalui suite pengujian End-to-End (E2E) dengan data nyata, socket jaringan aktual, dan database disk fisik**, agar **keandalan sistem terbukti secara empiris di lingkungan operasional nyata tanpa celah regresi tersembunyi yang tertutupi oleh data mockup/stub**.

## Kriteria Penerimaan (Acceptance Criteria)
- [ ] Diberikan gateway dijalankan pada ephemeral port TCP aktual (`127.0.0.1:0`), ketika client HTTP dan WebSocket asli melakukan handshake dan query, maka seluruh rute REST dan frame WS merespons sesuai kontrak protokol nyata tanpa stub.
- [ ] Diberikan konfigurasi aktif pada direktori filesystem riil, ketika mutasi JSON Patch dieksekusi, maka file fisik pada disk diperbarui secara atomik dan deteksi pergeseran (drift detection) bekerja saat berkas diubah dari luar tanpa mock store.
- [ ] Diberikan webhook channel menerima request HTTP berotentikasi, ketika signature HMAC SHA-256 diverifikasi dan egress outbound dieksekusi, maka proteksi security sandbox terbukti membuka koneksi hanya ke listener port yang diizinkan (zero bypass).
- [ ] Diberikan agent berjalan dengan SQLite database fisik di disk, ketika multi-turn turn diselesaikan dan proses di-restart, maka riwayat memori, session state, dan ledger audit dapat diakses utuh 100% tanpa manipulasi in-memory mockup.
- [ ] Dilarang keras menggunakan data mockup pada pengujian E2E (kecuali fallback default value resmi sistem).

## Cek INVEST
- **Independent**: Tiap alur pengujian mengisolasi domain pengujian spesifik (Gateway, Config, Channel, Memory) pada fixture riil independen.
- **Negotiable**: Cakupan skenario dapat diperluas per kanal atau per endpoint sesuai prioritas stabilitas.
- **Valuable**: Menghapus ketergantungan semu pada mock provider/mock transport yang rentan menyembunyikan bug runtime.
- **Estimable**: Berdasarkan suite test yang sudah ada di `tests/` dan integrasi crate galleon (estimasi 8 story points).
- **Small**: Terbagi menjadi 4 sub-task pengujian yang terukur dan dapat diverifikasi independen.
- **Testable**: Memiliki assertion kuantitatif via `cargo nextest run --test <target>` dengan status PASS.
