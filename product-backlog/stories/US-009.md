## Story
Sebagai **Owner Galleon Fleet**, saya ingin **seluruh produk core (backend, CLI, daemon, gateway, desktop) berjalan dari satu basis kode Rust dengan satu API gateway**, supaya **kontrak antar-komponen tidak bisa drift diam-diam ketika ownership modul berpindah, dan Web/Desktop berfungsi dengan binary yang sama yang dikirim di produksi**.

Sebagai **pengguna dashboard (Web/Desktop)**, saya ingin **semua panel (Fleet, Crow's Nest, Harbor, Settings, Remote Access, Terminal) menampilkan data nyata dari satu gateway**, supaya **saya tidak melihat error karena proses Go tidak berjalan, dan tidak tertipu oleh angka rekaan**.

## Kriteria Penerimaan
1. Given repo `galleon-fleet` pada akhir Sprint 13, When dijalankan `rg --files -g '*.go' -g 'go.mod' -g 'go.work'`, Then hasilnya kosong.
2. Given `galleon daemon` berjalan tanpa proses lain, When dashboard Web atau Desktop dibuka dan setiap panel dimuat, Then tidak ada request yang gagal karena koneksi ke `:9090`.
3. Given request tanpa token ke rute non-publik gateway, When dikirim, Then respons 401 — dibuktikan test tabel rute.
4. Given rute yang dikonsumsi UI/Desktop/CLI, When kontrak JSON-nya berubah tanpa update snapshot, Then CI merah.
5. Given CLI `galleon gateway` perintah admin (`get-paircode`, shutdown, SOP pending), When dijalankan terhadap gateway lokal, Then berhasil (bukan 404).
6. Given endpoint yang sebelumnya mengembalikan data rekaan (uptime, latency, provider, remedy, snapshot size), When dipanggil setelah migrasi, Then nilainya berasal dari sumber nyata atau `null`, tidak pernah konstanta karangan.
7. Given `[gateway.tls] enabled = true`, `path_prefix`, atau `[tunnel]` dikonfigurasi, When gateway dijalankan, Then konfigurasi itu benar-benar berlaku (TLS aktif, rute di bawah prefix, tunnel dijalankan) — dibuktikan test integrasi.

## Cek INVEST
- Independent: tidak bergantung pada fitur baru; hanya memindahkan dan memulihkan kapabilitas yang ada.
- Negotiable: daftar rute yang di-port ditentukan oleh inventaris konsumen (bukan seluruh Go).
- Valuable: menghapus satu bahasa/toolchain/proses, menutup celah keamanan teridentifikasi (termasuk TLS yang diabaikan, F-18), memulihkan CLI admin.
- Estimable: dipecah menjadi 7 backlog dan 55 task ≤ 1 jam (TASK-051..TASK-105).
- Small: tiap backlog muat satu sprint; story ini epic-level dan sengaja dipecah.
- Testable: kriteria 1–7 dapat dicek dengan perintah/test otomatis.
