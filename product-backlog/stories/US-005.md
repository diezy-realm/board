## Story
Sebagai **QA & Test Engineer Galleon**, saya ingin **mengarahkan ulang harness evaluasi `clawcrew-eval` ke interface engine Go dan membersihkan seluruh rujukan legacy RPC runtime**, agar **evaluasi trace model LLM tetap deterministik pada arsitektur hybrid baru dan tidak ada dead-code RPC yang tertinggal**.

## Kriteria Penerimaan (Acceptance Criteria)
- [ ] Diberikan harness `clawcrew-eval`, ketika replay trace dieksekusi, maka runner menggunakan interface engine Go (`StartTurn`/`ExecuteTurn`) tanpa mengubah file fixture trace yang ada.
- [ ] Diberikan kode gateway dan runtime, ketika di-audit terhadap legacy RPC subsystem, maka 0 rujukan legacy RPC tersisa.
- [ ] Seluruh suite evaluasi lulus 100% pada platform CI lokal.

## Cek INVEST
- **Independent**: Bergantung langsung pada penyelesaian strangler Go di Sprint 05.
