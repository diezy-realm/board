## Story
Sebagai **Product Owner & Release Engineer Galleon**, saya ingin **melakukan rename massal crate Rust, aplikasi TUI/binary, environment variable, direktori data, dan dokumen normatif ke identitas Galleon Fleet**, agar **seluruh produk konsisten dengan brand Galleon serta memenuhi standar kepatuhan hukum open-source dan ODR Owner**.

## Kriteria Penerimaan (Acceptance Criteria)
- [ ] Diberikan 27 crate Rust di `crates/`, ketika di-rename berurutan bawah-ke-atas dependency graph, maka crate `clawcrew-runtime` menjadi `galleon-runtime` paling terakhir dan `cargo check --workspace` lolos 0 error.
- [ ] Diberikan aplikasi `apps/zerocode` dan `apps/zerorelay`, ketika di-rename via git mv ke `apps/galleoncode` dan `apps/galleonrelay`, maka riwayat git commit terpreservasi utuh.
- [ ] Diberikan variabel lingkungan `CLAWCREW_*`, ketika dimigrasikan ke `GALLEON_*`, maka sistem berjalan tanpa dual-read alias.
- [ ] Diberikan direktori konfigurasi `~/.clawcrew`, ketika pengguna meng-upgrade, maka data otomatis termigrasi ke `~/.config/galleon`.
- [ ] Diberikan dokumen normatif (`AGENTS.md`, `CLAUDE.md`, standard-docs), ketika diperbarui ke nama Galleon, maka klausul atribusi lisensi ZeroClaw di `LICENSE` dan `NOTICE` terpreservasi utuh 100%.

## Cek INVEST
- **Independent**: Milestone akhir yang mengeksekusi rebranding setelah seluruh arsitektur stabil (Sprint 01 s.d. 07).
- **Negotiable**: Urutan rename crate mengikuti dependency graph cargo metadata.
- **Valuable**: Menyelesaikan transisi brand penuh ke Galleon Fleet.
- **Estimable**: Berdasarkan tiket T3-14 s.d. T3-24 (ODR-16..19).
- **Small**: Dipecah menjadi 5 sub-task terisolasi (TASK-042..046).
- **Testable**: Diverifikasi dengan `cargo build --workspace` dan scanner atribusi lisensi.
