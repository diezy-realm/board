## Story
Sebagai **DevOps & Infrastructure Engineer Galleon**, saya ingin **menyelesaikan pemisahan crate channel eksternal, menyediakan perintah instalasi daemon OS non-root, dan tooling migrasi state SQLite WAL**, agar **Galleon Fleet siap didistribusikan secara aman ke lingkungan produksi multi-platform**.

## Kriteria Penerimaan (Acceptance Criteria)
- [ ] Diberikan crate channel tersisa di monolith `clawcrew-channels`, ketika diekstrak ke crate independen `galleon-channel-*`, maka monolith channel bersih 100%.
- [ ] Diberikan perintah CLI `galleon service install/status/uninstall`, ketika dijalankan di Linux (systemd user unit) dan macOS (launchd plist), maka daemon berjalan di bawah user biasa tanpa privilege root.
- [ ] Diberikan database SQLite state dengan WAL mode aktif, ketika tooling migrasi dieksekusi, maka checkpoint WAL berjalan aman dengan zero data loss.

## Cek INVEST
- **Independent**: Menuntaskan integrasi packaging platform sebelum rebranding final.
- **Negotiable**: Format unit file disesuaikan dengan standar OS Linux/macOS.
- **Valuable**: Menjamin keamanan instalasi daemon (least-privilege) dan integritas data user.
- **Estimable**: Berdasarkan tiket T3-03, T3-20 (BL-10), dan T3-21 (BL-11).
- **Small**: Terbagi ke dalam 3 sub-task (TASK-039..041).
- **Testable**: Diverifikasi dengan instalasi systemd dry-run dan checkpoint SQLite.
