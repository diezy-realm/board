## Story
Sebagai **Tech Lead & Backend Developer Galleon**, saya ingin **merampingkan crate `clawcrew-runtime` dengan memindahkan logika orkestrasi turn dan session loop ke engine Go menggunakan pola strangler**, agar **ukuran runtime Rust menyusut, arsitektur hybrid Go-Rust berjalan optimal, dan dependensi tidak lagi monolitik**.

## Kriteria Penerimaan (Acceptance Criteria)
- [ ] Diberikan subsistem `clawcrew-runtime`, ketika turn execution didelegasikan ke engine Go (`engine/`), maka gateway dapat menjalankan turn secara transparan tanpa mengubah kontrak REST/WS eksternal.
- [ ] Diberikan boundary FFI/gRPC antara gateway Rust dan engine Go, ketika request diproses, maka trace, context, dan error tertranslasi sempurna.
- [ ] Diberikan modul yang telah dimigrasi, ketika dependensi internal dibersihkan, maka ukuran LOC dan kompilasi `clawcrew-runtime` berkurang drastis tanpa regresi.

## Cek INVEST
- **Independent**: Berjalan mandiri setelah Sprint 04 E2E testing mengunci baseline fungsional.
- **Negotiable**: Batas modul strangler dapat diatur per-concern (turn, memory, tool dispatch).
- **Valuable**: Fondasi krusial sebelum rename massal di Sprint 08.
- **Estimable**: Berdasarkan tiket T3-05 (BR-D1) Dev Task 3.
- **Small**: Dipecah menjadi 3 sub-task berantai (TASK-034..036).
- **Testable**: Diverifikasi dengan replay trace dan `cargo nextest`.
