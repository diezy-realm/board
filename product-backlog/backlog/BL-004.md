## Deskripsi
Melakukan dekomposisi struktural pada 3 file produksi gateway yang berukuran >2.000 baris (`api_config.rs`: 4.940 baris, `ws.rs`: 4.259 baris, `api_sections.rs`: 2.413 baris) menjadi direktori modul (`api_config/`, `ws/`, `api_sections/`) sesuai mandat tiket T3-04 / BR-C7.

Penerapan mengikuti pola SAFE RF-A:
1. Pindahkan berkas utama menjadi modul direktori dengan `mod.rs`.
2. Pisahkan modul unit test inline (`mod tests`) ke `tests.rs` terpisah.
3. Ekstrak handler domain spesifik (misal: JSON patch, drift detection, session loop, connection handling) ke submodule internal.
4. Jaga stabilitas API publik melalui `pub use` di `mod.rs` sehingga zero breaking changes untuk caller internal maupun eksternal.
