## Deskripsi
Menerapkan arsitektur strangler pattern pada `clawcrew-runtime` untuk memindahkan logika eksekusi turn, state orchestration, dan context window management dari modul Rust yang membengkak ke domain engine Go (`engine/domain/crew`). 

Langkah mencakup:
1. Pembuatan façade interface gRPC/IPC antara gateway Axum dan engine Go.
2. Penyusutan modul `clawcrew-runtime/src/agent/turn/` menjadi pemanggil adaptor tipis.
3. Pembersihan dead-code dan perampingan dependensi workspace pada runtime crate.
