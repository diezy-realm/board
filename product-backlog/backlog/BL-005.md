## Deskripsi
Membangun dan mengeksekusi suite pengujian End-to-End (E2E) menyeluruh pada Galleon Fleet yang menguji integrasi lintas subsistem (Gateway, Config, Channel, Memory) menggunakan socket TCP aktual, berkas filesystem fisik, signature kriptografi nyata, dan database SQLite riil pada disk.

Sesuai mandat arsitektur:
1. **Zero Mock Transport**: Gateway diuji dengan binding port TCP ephemeral `127.0.0.1:0` dan client HTTP/WS nyata.
2. **Zero Mock File/Storage**: Konfigurasi dan memori diuji langsung terhadap berkas disk nyata (`tempfile`), menguji pembacaan, penulisan atomik, dan recovery pasca-restart.
3. **Zero Fake Credentials/Bypass**: Validasi signature webhook channel menggunakan implementasi HMAC SHA-256 asli.
4. **Zero Stub Egress**: Egress outbound diuji melalui socket listener lokal untuk memvalidasi kebijakan keamanan pembatasan jaringan.
5. **No Mockup Data**: Seluruh payload pengujian menggunakan format data nyata dan valid, tanpa dummy/mockup buatan kecuali fallback default value yang disyaratkan schema.
