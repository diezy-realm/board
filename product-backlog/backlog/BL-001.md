## Deskripsi
Tambah field `optional string agent_alias = 8;` (nomor field menyusul slot kosong berikutnya,
cek `proto/agent_service.proto` sebelum menetapkan nomor pasti) ke `ExecuteTurnRequest`. Field ini
dikirim Go (dari `CrewMember.AgentAlias`, lihat BL-002) dan dipakai Rust untuk resolve
`config.agents.get(agent_alias)` di titik `ExecuteTurn` handler
(`crates/clawcrew-gateway/src/grpc_system_gateway.rs`, cari fn yang implement RPC ini).

**Backward compatibility wajib**: field opsional, request TANPA `agent_alias` tetap jalan seperti
sekarang (fallback ke `model` string polos apa adanya) — tidak boleh breaking existing caller.
