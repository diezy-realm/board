## 1. Tujuan (Objective)
Menjadikan `galleon-fleet` satu produk Rust (+ TypeScript untuk `web/`) dengan **satu API gateway**, sehingga:

1. **Kontrak tidak bisa drift diam-diam.** Saat ini Rust mengabaikan `system_prompt`, `tools`, `max_tokens` dari Go, tool-calling lintas boundary mati, dan Go menandai turn sukses walau stream putus (RES baseline F-03). Dengan satu bahasa, kontrak = tipe Rust + snapshot test.
2. **Produk yang dikirim utuh.** Image produksi dan sidecar desktop hanya menjalankan Rust, tetapi dashboard memanggil Go `:9090` (F-02) → panel error.
3. **API Rust pulih.** Router produksi hanya ±23 rute; CLI admin/pairing 404 (F-01).
4. **Dashboard jujur.** Uptime 99,98%, latency 14 ms, daftar provider, hasil "remedy", ukuran snapshot saat ini konstanta (F-13). Untuk produk "organisasi AI", data rekaan merusak kepercayaan.
5. **Aman secara default.** Menutup S-01…S-07 (F-04).

Kaitan dengan goal produk: ODR-03 (fokus "Organisasi AI" yang persisten) membutuhkan fondasi yang bisa dipercaya; dua bahasa dengan kontrak tak terjaga bertentangan dengan itu.

## 3. Asumsi (Assumptions)
- Pernyataan Owner: pekerjaan board sprint 04–08 selesai 100%. Snapshot board `de99aff` masih menampilkan beberapa task `blocked`; drift ini dicatat di RPT-108 dan tidak memblokir program.
- Pengguna single-tenant, lokal-first (ODR-05). Tidak ada kebutuhan multi-writer untuk data dashboard → file JSON atomik cukup.
- Data dashboard pengguna yang sudah ada berada di `engine/data` (CWD repo) atau `GALLEON_DATA_DIR`/`FLEET_DATA_DIR` (F-06b).
- Agent `agy` mengerjakan task dengan toolchain Rust 1.96.0 (`rust-toolchain.toml`), cargo-nextest, dan untuk Sprint 09–10 masih punya Go 1.27 untuk kontainmen & rekam fixture.
- **Koreksi atas asumsi awal:** web **belum** punya alur auth. Dari 20 `fetch('/api/...')` di `web/src/utils/apiClient.ts`, hanya eksekusi terminal yang mengirim Bearer, dan tidak ada kode yang pernah menyimpan `galleon_auth_token` (RES baseline F-15). Gateway Rust mewajibkan pairing secara default. Karena itu cutover butuh layar pairing di web (R-07a) — ini satu-satunya perubahan UX yang terlihat pengguna dari program ini.
- Pengguna dapat memperoleh kode pairing dari `galleon gateway get-paircode` (CLI, `src/main.rs:8513`) setelah rute admin dipulihkan di Sprint 10.
- Komponen Rust yang dibutuhkan sudah ada (F-10); port tidak butuh dependensi baru.

## 5. Di Luar Lingkup & Pertanyaan Terbuka (Out of Scope / Open Questions)
- Di luar lingkup:
  - Membangun Squad/Ship/Mission/Treasury/Entitlement/Learning yang di Go tidak terhubung (ODR-31).
  - Mengganti penyimpanan JSON dashboard ke SQLite (ODR-32).
  - Pemecahan besar `galleon-runtime`; hanya satu ekstraksi berisiko rendah (`tunnel`, Sprint 15).
  - SDK/add-on Go (repository terpisah, ODR-30).
  - Memulihkan semua 152 rute lama; hanya yang punya konsumen.
  - Postgres store Go (`engine/pkg/store/postgres`) — tidak di-port.
  - `/api/turn`, `/api/query`, `/api/v1/{crews,runs,tasks,tools,tool-requests,workflows,approvals,artifacts,entitlement/usage}`, `/api/engine/execute`, `/api/terminal/audit`, `/test/runs` — tidak ada konsumen di web (RES baseline §3); dikonfirmasi ulang untuk Tauri/CLI di TASK-058.
- Pertanyaan terbuka (default dipakai bila belum dijawab saat Sprint 11 diaktifkan):
  - Q1 Learning proposals (`/api/v1/learning/proposals*`): handler Go tidak terpasang sehingga UI sudah 404 hari ini. **Default:** sembunyikan UI, tidak di-port. → (jawaban + tanggal)
  - Q2 Snapshot (`/api/snapshots`): Go hanya menyimpan metadata rekaan di memori. **Default:** port sebagai snapshot nyata (salin file koleksi ke `snapshots/<id>/`). → (jawaban + tanggal)
  - Q3 Quartermaster intent "objective": Go membalas "I will draft a Fleet Order proposal…" walau tidak ada yang dibuat. **Default:** diperlakukan sebagai chat biasa via agent Rust, tanpa klaim draft. → (jawaban + tanggal)
  - Q4 Sonar: apakah ada instance SonarQube Cloud/Server? **Default:** konfigurasi disiapkan, job CI hanya jalan bila secret `SONAR_TOKEN` ada. → (jawaban + tanggal)
  - Q5 Alur pairing web: cukup kode pairing manual dari CLI/log daemon? **Default:** ya (tanpa auto-pair localhost, agar tidak membuka bypass auth). → (jawaban + tanggal)
  - Q6 Sumber seed: `engine/data` (yang disajikan Go hari ini) atau `web/data` (tidak dipakai kode, isi berbeda)? **Default:** `engine/data`; `web/data` dihapus di Sprint 13 (RES baseline F-16). → (jawaban + tanggal)
  - Q7 `target_release`: versi/tanggal rilis yang diinginkan Owner. → (jawaban + tanggal)
  - Q8 TLS/`path_prefix`/tunnel tidak lagi dijalankan sejak `db18a3745` walau config masih ada. **Default:** dipulihkan dari kode lama (Sprint 15); TLS diprioritaskan karena keamanan. → (jawaban + tanggal)
  - Q9 mDNS advertisement (`crates/galleon-gateway/src/nodes/mdns.rs` ada, tidak dipasang). **Default:** tidak dipulihkan sampai ada konsumen di inventaris TASK-058. → (jawaban + tanggal)
