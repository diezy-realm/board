## Ringkasan (Summary)
Telah menyelesaikan implementasi command instalasi daemon service OS non-root (SPEC-008, T3-20, BL-008). CLI mendukung subcommands `service install`, `service status`, dan `service uninstall` secara simetris baik dipanggil via `galleon` maupun `clawcrew`. Pada Linux, service unit systemd user dihasilkan di `~/.config/systemd/user/galleon.service` tanpa privilege root (`is_root()` enforcement), menggunakan `systemctl --user`. Pada macOS, plist launchd user dihasilkan di `~/Library/LaunchAgents/com.galleon.fleet.plist`. Seluruh siklus uninstall dan status mendukung backward compatibility pembersihan service warisan (`clawcrew.service` dan `com.clawcrew.daemon.plist`). PR #89 telah dibuka ke branch `testing`, seluruh gate dev-ci Required Gate berstatus hijau, dan telah berhasil di-merge ke `testing`.

## Yang Dikerjakan (What Was Done)
1. **Implementasi Service Installer Non-Root (`crates/clawcrew-runtime/src/service/mod.rs`)**:
   - Memperbarui label service default menjadi `com.galleon.fleet` dengan fallback/legacy label `com.clawcrew.daemon`.
   - Mengarahkan default Linux unit file ke `~/.config/systemd/user/galleon.service` dan unit macOS ke `~/Library/LaunchAgents/com.galleon.fleet.plist`.
   - Mengonfigurasi `install_linux_systemd` untuk menghasilkan unit systemd user murni non-root dengan metadata lengkap: `Description=Galleon Fleet Autonomous Daemon`, `Documentation=https://github.com/diezy-realm/galleon-fleet`, `Restart=on-failure`, `RestartSec=5`, `Environment=GALLEON_CONFIG_DIR=%h/.config/galleon`, serta auto reload dan enable via `systemctl --user`.
   - Mengonfigurasi `uninstall_linux` dan `uninstall` macOS untuk menghapus dan mematikan unit secara simetris, termasuk pembersihan backward-compatible untuk unit legacy `clawcrew.service` dan `com.clawcrew.daemon.plist`.
   - Memastikan `is_root()` guard memblokir instalasi user-level bila dieksekusi dengan akun root (keamanan least-privilege).
2. **Pengujian Unit & Komponen**:
   - Menambahkan unit tests di `clawcrew-runtime`: `linux_systemd_user_service_is_non_root`, `macos_launch_agent_service_file_is_user_level`, dan `render_macos_launch_agent_plist_contains_galleon_metadata`.
   - Menambahkan komponen CLI test di `tests/component/service_cli.rs` yang menguji invokasi `service install --help`, `service status --help`, dan `service uninstall --help`.
3. **Penyelarasan Mutu & CI**:
