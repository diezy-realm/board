## Ringkasan (Summary)
Menyelesaikan tiket TASK-020 untuk memutus 4 referensi sisa ke `clawcrew_runtime::` di gateway subsistem agent (`crates/clawcrew-gateway/src/ws.rs` 3 referensi, `crates/clawcrew-gateway/src/lib.rs` 1 referensi). ## Yang Dikerjakan (What Was Done)
1. **Ekspansi SSOT Leaf (`crates/clawcrew-api/src/agent.rs`):**
   - Menambahkan tipe domain `AgentContextLimits`, `AgentSafeguardKind`, `AgentSafeguardFallback`, `AgentTurnSuccess`, `AgentTurnError`.
   - Mendefinisikan trait `AgentSession` (termasuk downcasting hook `channel_handles_any`, context limits, restart/cancel controls).
   - Mendefinisikan trait `AgentRunner` dan global registry (`set_agent_runner`, `get_agent_runner`, `process_message`, `create_agent_session`).
2. **Channel Handles Support (`crates/clawcrew-tools/src/send_via.rs`):**
   - Mendefinisikan struct `AgentChannelHandles` di `clawcrew-tools` yang dapat di-downcast aman tanpa menciptakan cyclic dependency antara `clawcrew-runtime` dan `clawcrew-channels`.
3. **Runtime Wiring & Delegator Registration:**
   - Mengimplementasikan `AgentSession` untuk `Agent` pada `crates/clawcrew-runtime/src/agent/agent/mod.rs`.
   - Mengimplementasikan `RuntimeAgentRunner` dan fungsi `install_agent_runner()` di `clawcrew-runtime`.
   - Memanggil `crate::agent::install_agent_runner()` saat inisialisasi daemon di `crates/clawcrew-runtime/src/daemon/mod.rs`.
4. **Decouple Gateway `ws.rs`:**
   - Baris 504: menggantikan pembuatan agent dengan `clawcrew_api::agent::create_agent_session`.
   - Baris 625: channel handle downcasting menggunakan `clawcrew_tools::send_via::AgentChannelHandles`.
   - Baris 1018 & 1390: mengganti tipe parameter fungsi menjadi `&(dyn clawcrew_api::agent::AgentSession + '_)` dan `&mut (dyn clawcrew_api::agent::AgentSession + '_)`.
5. **Decouple Gateway `lib.rs` (Jalur Produksi Chat):**
   - Baris 1141: menggantikan `clawcrew_runtime::process_message(...)` dengan `clawcrew_api::agent::process_message(Box::new(config), ...)`.
   - Menambahkan regression test unit suite `chat_regression_tests` yang menguji `run_gateway_chat_with_tools` dan `process_message` pada kondisi sukses maupun penanganan error propagation.
