## Ringkasan (Summary)
Mengimplementasikan resolusi runtime `SopStep.agent` terhadap `config.agents.get(alias)` di titik eksekusi SOP engine (`crates/clawcrew-runtime/src/sop/engine/mod.rs` dan `crates/clawcrew-runtime/src/sop/mod.rs`). Jika alias valid di `config.agents`, step mengeksekusi dengan konfigurasi agen (`model_provider` dan `skill_bundles`) dari entri tersebut. Jika tidak valid atau kosong, engine fallback secara aman ke default agent SOP (`sop.agent`) atau default global (`None`) tanpa crash/panic, disertai warning log terstruktur. Seluruh kriteria penerimaan terpenuhi, `cargo check --workspace` dan unit test lolos, serta PR #63 telah dibuka ke branch `testing`.

## Yang Dikerjakan (What Was Done)
- Mempertahankan rendering teks prompt `agent: {agent}` di `crates/clawcrew-runtime/src/sop/mod.rs:1200` sesuai kontrak.
- Menambahkan field `agents: Option<HashMap<String, AliasedAgentConfig>>` serta builder/setter helper (`with_agents`, `with_root_config`, `set_agents`, `set_root_config`, `agents`) pada `SopEngine`.
- Menambahkan metode `resolve_step_agent(&self, step: &SopStep, sop: &Sop) -> Option<String>` dan `resolve_step_agent_with_map(...)` menggunakan pola `agents_map.get(alias)`.
- Mengimplementasikan `resolved_agent_config_for_step` untuk mendapatkan referensi `AliasedAgentConfig` (model provider & skill bundles) bagi step tertentu.
- Memperbarui titik eksekusi dan evaluasi RACI:
  - `clear_waiting_gate` (titik eksekusi kelanjutan dari waiting gate).
  - `resolve_step_action` (titik resolusi aksi step berikutnya, termasuk start run).
  - Pengecekan RACI constraint saat evaluasi gate / pra-eksekusi.
- Memastikan fail-closed / safe fallback: jika alias tidak ditemukan di `config.agents`, mencatat log peringatan `WARN` terstruktur melalui `clawcrew_log::record!` dan melakukan fallback ke `sop.agent`, atau `None` jika SOP tidak memiliki agent default. Tidak ada pemanggilan `.unwrap()` atau `.expect()` tanpa invariant.
- Menambahkan 3 unit test komprehensif di `crates/clawcrew-runtime/src/sop/mod.rs`:
  - `test_sop_step_agent_resolves_valid_alias_from_config_agents`
  - `test_sop_step_agent_invalid_alias_falls_back_to_sop_default_without_crash`
  - `test_sop_step_agent_invalid_alias_with_no_sop_parent_falls_back_to_none_without_crash`
