## Ringkasan (Summary)
Telah diimplementasikan sistem self-healthcheck dan liveness monitoring milik agy sendiri (`subagent-healthcheck`) untuk memantau sub-agent dan background task child yang di-spawn oleh agy. Sistem mengeksekusi Rule A (kill child tanpa progres > 30 menit) dan Rule C (reap zombie OS / defunct), dengan jaminan **PRINSIP KERAS: PARENT agy dan bridge JANGAN PERNAH di-kill**. Sistem dibuat seutuhnya sebagai environment internal agy (skrip Python, sidecar cron schedule, steering global `GEMINI.md`, skill agy, dan daemon schedule builtin). Seluruh 3 skenario tes penerimaan telah lulus 100%.

## Yang Dikerjakan (What Was Done)
1. **Analisis Pola Spawning Sub-Agent & Sinyal Progres:**
   - Memeriksa mekanisme spawning sub-agent melalui SDK (`antigravity-sdk-python`), CLI `agentapi`, dynamic workflow (`run-workflow`), serta background process tree.
   - Mengidentifikasi PID parent agy (`comm: agy`, `PPID: bridge`), bridge runner (`run_standalone.py`, `board_agy_bridge.py`), dan relasi proses anak di `/proc`.
   - Mengimplementasikan pengukuran progres berbasis fakta: delta I/O (`wchar`, `write_bytes` via `/proc/{pid}/io`), delta CPU (`utime`, `stime` via `/proc/{pid}/stat`), serta aktivitas penulisan file/log terbuka.
2. **Implementasi Engine Healthcheck Internal:**
   - Dibuat skrip Python mandiri: `/home/diezy/.gemini/scripts/subagent_healthcheck.py` (executable, disymlink ke `/home/diezy/.gemini/antigravity-cli/bin/subagent-healthcheck`).
   - Menerapkan **Immunity Guard** mutlak: PARENT agy (`agy_pids`), bridge (`bridge_pids`), dan sistem (`PID <= 2`) masuk ke set `NEVER_KILL_PIDS`. Target terminasi HANYALAH proses child/descendant di bawah parent agy (`pid != parent_agy_pid`).
   - Menerapkan **Rule A**: child dengan umur >= 30m (1800 detik) yang CPU delta = 0 dan I/O delta = 0 serta tanpa aktivitas file terbuka akan dikirim sinyal `SIGTERM` lalu `SIGKILL`. Child yang masih aktif berprogres tidak akan disentuh.
   - Menerapkan **Rule C**: child berstatus `'Z'` (`<defunct>`) atau orphan tanpa proses anak langsung di-reap/terminate.
   - Mematikan child hang/zombie secara otomatis mengembalikan kontrol ke parent agy (`wait()` pada child selesai) tanpa menyentuh parent.
3. **Konfigurasi Environment, Sidecar & Steering:**
   - **Sidecar builtin schedule:** Dibuat di `~/.gemini/jetski/sidecars/subagent-healthcheck/sidecar.json` dan `~/.gemini/config/sidecars/subagent-healthcheck/sidecar.json` (`cadence: */30 * * * *`).
   - **Steering Global:** Ditambahkan Bagian 8 pada `~/.gemini/GEMINI.md` (memastikan aturan melekat lintas sesi).
   - **Skill agy:** Dibuat di `~/.gemini/antigravity-cli/builtin/skills/subagent-liveness/SKILL.md` dan `~/.gemini/config/skills/subagent-liveness/SKILL.md`.
   - **Daemon Schedule builtin:** Diaktifkan via tool `schedule` dengan `CronExpression="*/30 * * * *"` (`IsDaemon=true`).
   - **Log Kanonikal:** Dikonfigurasi di `/home/diezy/.gemini/antigravity-cli/log/subagent-healthcheck.log`.
4. **Verifikasi Pengujian Lengkap (3 Skenario):**
   - Menulis dan mengeksekusi test suite komprehensif `/home/diezy/.gemini/scripts/test_subagent_healthcheck.py`:
     - Test (a): Child sengaja di-hang (sleep) -> Rule A terpicu -> Child di-kill (signal -15) -> Parent agy tetap hidup dan kontrol kembali.
     - Test (b): Child sehat aktif menulis file -> I/O delta terdeteksi -> Rule A dilewati (child tidak di-kill).
     - Test (c): Parent agy & bridge immunity -> dievaluasi agresif dengan threshold 0 detik -> Parent agy dan bridge terbukti 100% aman dan tak tersentuh.
