## Ringkasan (Summary)
Telah diselesaikan retargeting harness evaluasi LLM pada crate `clawcrew-eval` agar mereplay fixtures trace ke domain interface Go engine (`StartTurn` / `GoEngineTurnService`) sesuai spesifikasi SPEC-007 / T3-06 (BR-D2). Replay runner kini menggunakan trait abstraksi `GoEngineTurnService` dan adapter in-process `MockGoEngineTurnClient` yang memancarkan structured events (`ToolCallStarted`, `ToolCallFinished`, `TextChunk`, `TurnCompleted`) serta menjaga turn boundary secara ketat. Seluruh berkas data fixture historis dipertahankan tanpa perubahan byte sedikit pun (100% identik).

## Yang Dikerjakan (What Was Done)
1. **Definisi Kontrak Go Engine Turn Service**: Menambahkan model data IPC Go engine `GoTurnRequest`, `GoTurnEvent`, `GoTurnEventType`, `GoTurnOutcome`, dan trait `GoEngineTurnService` pada `crates/clawcrew-eval/src/runner.rs`.
2. **Implementasi `MockGoEngineTurnClient`**: Membangun client engine evaluasi yang mengisolasi agent loop, mengemulasikan interface Go engine `StartTurn`, mengumpulkan token dan panggilan tools, serta memancarkan event proto Go yang terstruktur.
3. **Refactoring Replay Runner**: Memisahkan eksekusi runner ke `run_case_with_service` sehingga runner eval sepenuhnya agnostik terhadap implementasi konkret Go engine (mendukung mock deterministik maupun live service).
4. **Verifikasi Keutuhan Fixture**: Memverifikasi integritas 9 file fixtures di `evals/regression/*.json` dengan md5 checksum sebelum dan sesudah perubahan untuk menjamin 0 byte termodifikasi.
5. **Verifikasi Test Suite**: Menambahkan unit test event streaming Go engine dan memverifikasi seluruh 72 test (68 unit test + 4 regression suite test) lulus 100%.
