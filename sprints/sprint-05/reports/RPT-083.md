## Ringkasan (Summary)
Memperbaiki kelemahan terminal outcome pada boundary strangler gateway (`crates/clawcrew-gateway/src/strangler_runner.rs`) sesuai SPEC-010 Bagian A (BL-084 / TASK-047). Sebelumnya, kondisi stream terputus tanpa terminal event (`Ok(None)`) dan event selesai sukses (`TurnCompleted`) sama-sama mengeksekusi `break` ke pembentukan `Ok(AgentTurnSuccess)`, sehingga stream EOF prematur dianggap turn sukses palsu. Masalah ini diselesaikan dengan memperkenalkan flag boolean lokal `terminal_event_received: bool = false`, di mana hanya penerimaan event `TurnCompleted` yang menandai sukses, sedangkan stream yang berakhir sebelum event terminal mengembalikan `Err(AgentTurnError)` dengan mempertahankan `committed_response` (partial output tidak hilang).

## Yang Dikerjakan (What Was Done)
1. **Flag Terminal Event**: Menambahkan `terminal_event_received: bool = false` sebelum event loop gRPC di `StranglerAgentSession::turn_streamed_with_steering_state`.
2. **Penandaan Sukses Eksplisit**: Mengatur `terminal_event_received = true` hanya saat cabang `resp.r#type == EventType::TurnCompleted as i32` tercapai sebelum `break`.
3. **Pemisahan Jalur EOF Prematur dari Sukses**:
   - Menjaga cabang `Ok(None)` agar keluar dari loop dengan komentar dokumentasi.
   - Setelah loop berakhir dan sebelum membangun `AgentTurnSuccess`, melakukan validasi `if !terminal_event_received`.
   - Mengembalikan `Err(AgentTurnError { error: anyhow::anyhow!("AgentEngine stream closed before TurnCompleted"), committed_response: accumulated_response, new_messages: Vec::new() })`.
   - Jalur error event (`EventType::Error`) dan transport error (`Err(status)`) dipertahankan tanpa perubahan.
4. **Unit Testing & Mocking**:
   - Merefaktor `MockAgentEngine` pada modul `tests` di `strangler_runner.rs` menggunakan enum `MockBehavior` (`Success`, `ErrorEvent`, `PrematureClose`).
   - Menambahkan unit test baru `test_strangler_agent_session_premature_stream_closure` yang mensimulasikan stream terputus prematur setelah menerima sebagian text chunk:
     - Memverifikasi turn mengembalikan `Err(AgentTurnError)`.
     - Memverifikasi pesan error memuat `"AgentEngine stream closed before TurnCompleted"`.
     - Memverifikasi `committed_response` tetap berisi partial output (`"Partial output before crash"`).
     - Memverifikasi `new_messages` kosong.
   - Memverifikasi 5 unit test existing di `strangler_runner.rs` tetap lulus tanpa regresi.
